## MailerLite Implementation Guide

### Step 1: Create the Automation Workflow

1. Log in to your MailerLite dashboard
2. Go to **Automations** → **Create Workflow**
3. Choose trigger: **Subscriber joins a group** (your main newsletter list)
4. Name the workflow: "Manhattan Money Kings Welcome Sequence"

### Step 2: Set Up Each Email

For each email in the sequence:

1. Add **Delay** node (set timing as specified above)
2. Add **Email** node
3. Copy the subject line and email body from this document
4. Add your BookFunnel link and Amazon links
5. Include unsubscribe link at the bottom (required by law)

### Step 3: Add Conditional Logic (Optional)

To avoid sending sales emails to people who already purchased:

1. Add **Condition** node: "Has clicked link to Amazon"
2. If YES: Skip sales emails, send engagement content instead
3. If NO: Continue with sales sequence

### Step 4: Test the Workflow

1. Add yourself as a test subscriber
2. Verify all emails send at correct intervals
3. Check that all links work correctly
4. Test on mobile and desktop

### Step 5: Monitor Performance

Track these metrics in MailerLite:

- **Open Rate:** Aim for 30-40% (adjust subject lines if lower)
- **Click Rate:** Aim for 5-10% (test different CTAs if lower)
- **Conversion Rate:** Track Amazon affiliate clicks or sales
- **Unsubscribe Rate:** Should be under 2% (if higher, reduce email frequency)

### Step 6: Optimize Over Time

- A/B test subject lines
- Try different send times
- Adjust email length based on engagement
- Update book prices and links as needed

## Best Practices

### Subject Lines
- Keep under 50 characters for mobile optimization
- Use emojis sparingly (1-2 max)
- Create urgency without being spammy
- A/B test different approaches

### Email Body
- Keep paragraphs short (2-3 sentences max)
- Use white space generously
- Include clear, prominent CTAs
- Make it easy to skim
- Always include an unsubscribe link

### Timing
- Don't email too frequently (every 3-4 days is ideal)
- Respect subscriber preferences
- Monitor unsubscribe rates
- Adjust timing based on engagement

### Personalization
- Use [First Name] merge tags
- Segment based on behavior (clicked vs. didn't click)
- Send different content to engaged vs. unengaged subscribers
- Reply personally to reader responses
