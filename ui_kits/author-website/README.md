# Author Website Kit — Reese Astor

The full reeseastor.com landing recreation.

**Source of truth:** `REESE/B3-The Billionaire's Baby Secret/Home.tsx` (Vite + Tailwind + lucide-react + shadcn/ui). This kit is a hand-rebuilt, dependency-free copy that preserves the visual contract.

## Components

| Component | Purpose |
|---|---|
| `TopNav` | Sticky, blurred 72px header. Cinzel wordmark, Inter nav, gold CTA. |
| `BookHero` | 2-col hero: glowing cover left, eyebrow / title / tagline / CTAs / trope pills right. |
| `SectionHeading` | Eyebrow + Playfair display heading + gold hairline. Standard for every section. |
| `BookCard` | Hover-lifting series card: cover with halo, eyebrow, title, blurb, status badge. |
| `PraiseQuote` | Editorial pull quote with Cinzel quote-mark, gold hairline + attribution. |
| `NewsletterBand` | Full-bleed gold-glow CTA band. Email input + primary submit + post-submit state. |
| `SiteFooter` | 4-column dark footer with imprint + nav columns. |
| `RAButton` | Primary / outline / ghost button primitive. |

## How to use

Open `index.html` — it's a runnable demo wiring all components into the homepage. Copy components by name from `components.jsx`.

## Screens covered
- Home (hero · series · praise · newsletter · footer)

> Codebase covers only the homepage; About / Books / Blog screens are not in source. The kit ships components reusable for those pages — author bio, book detail, blog index — but no isolated screens are mocked. Flag if you want me to invent them.
